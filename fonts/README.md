# Fonts

- `sl-large.bdf` (mode 1) and `sl-small.bdf` (mode 2) are proportional pixel
  fonts in the style of SL's platform signs. They are drawn by hand in
  [`tools/make_sl_font.py`](../tools/make_sl_font.py); edit the glyphs there and
  run the script to regenerate the files.
- `9x18B.bdf` (used for the clock) is an X11 "misc-fixed" font by Markus Kuhn,
  copied from [hzeller/rpi-rgb-led-matrix/fonts](https://github.com/hzeller/rpi-rgb-led-matrix/tree/master/fonts).
  It is in the public domain.
