# Fonts

- `sl-departures.bdf` is a bold, proportional pixel font in the style of SL's
  platform signs. It is drawn by hand in [`tools/make_sl_font.py`](../tools/make_sl_font.py);
  edit the glyphs there and run the script to regenerate the file.
- `9x18B.bdf` (used for the clock) is an X11 "misc-fixed" font by Markus Kuhn,
  copied from [hzeller/rpi-rgb-led-matrix/fonts](https://github.com/hzeller/rpi-rgb-led-matrix/tree/master/fonts).
  It is in the public domain.
